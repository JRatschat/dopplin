# Dopplin

Dopplin is a two-player climbing and shedding game where players bid contracts and Aces shovel sets.

👉 View the game on BoardGameGeek:
https://boardgamegeek.com/boardgame/474110/dopplin

Designer Diary: https://boardgamegeek.com/blog/16873/blogpost/188454/dopplin-on-designing-a-card-game-that-feels-tradit

## Repository Contents

This repository contains:
- The official **rules**
- **Assets and materials** for playing the game in real life and online

Play Dopplin online against bots or friends: https://play.cards/dopplin
